# 行测接入共享粉笔身份：现状与待定契约（2026-09-23）

本文件是接入前审计，不代表共享身份接口已经实现或发布。所有验证应使用合成账号，不读写真实题目和复盘记录。

## 已确认的行测边界

| 环节 | 当前实现 | 接入影响 |
| --- | --- | --- |
| 登录 | `fenbi-cloud` 生成并轮询粉笔二维码。成功后按粉笔 providerId 派生 `provider_key`，查找或建立 `xc_fb_accounts`，签发 30 天的随机站内令牌，数据库只存令牌哈希。 | 可保留行测本地会话格式，但需要可信、一次性的共享身份兑换入口。不能将公专令牌当行测令牌使用。 |
| 浏览器会话 | `pithiest-xingce-fenbi-session-v1` 保存 `{token, accountId}`；请求只向行测 `fenbi-cloud` 的 Authorization 头发送令牌。 | 现有账户切换和缓存按 `accountId` 工作；兑换结果须先验证账号归属再写入，令牌不得进入 URL、日志或跨域本机存储。 |
| 账号数据 | `xc_fb_accounts.id` 是独立 UUID；错题、进度、练习及详情全部由服务端根据行测会话定位账号。 | 共享身份必须映射到原行测账号，不能按昵称或公专 UUID 新建重复账号。旧笔记、练习与复盘不得迁移覆盖。 |
| 粉笔授权 | 粉笔 cookies 在行测服务端以行测专属 Vault 运行密钥加密；`provider_key` 也使用该密钥派生。 | 公专的密文和 `provider_key` 不能直接读取或比较。首次只在公专扫码的用户，需要约定安全的服务端授权交接或统一题源读取服务。仅证明身份不足以让行测开始同步粉笔历史。 |
| 退出与失效 | 本机先隐藏账号，再请求 `/logout` 删除行测会话；401 清除本地会话。`/disconnect` 只停止自动读取并保留记录。 | 必须定义“退出此账号”是双站退出还是仅行测退出，并防止共享身份仍有效时自动重新登录。停止自动同步不能被普通共享身份兑换悄悄恢复。 |
| 本机与离线 | 练习缓存按账号存在 localStorage，错题本按账号存在 IndexedDB；匿名导入另存。请求在账号卸载时 abort，离线可看本机缓存。 | 切换身份前隐藏旧账号并中止请求；离线时只显示已验证身份的缓存，不把匿名导入或旧账号内容自动并入新账号。 |

## 建议的最小接入契约（等待总控确定）

1. 中枢签发仅给行测使用、短时、一次性的身份断言或兑换码。行测服务端验证签发方、受众、有效期、重放和粉笔身份；浏览器不传递现有公专/行测令牌，也不把任何令牌放入 URL。
2. 行测服务端用**自己**的运行密钥重新计算 provider_key，原账号存在时只签发其站内会话；不存在时按既定账号创建流程建立。响应沿用 `{ token, account: { accountId, ... } }` 或明确的新版本格式，以减少客户端改动。
3. 契约必须定义首次进入行测时的粉笔授权来源：可信服务端通道提供可用于行测同步的授权材料，或由共享服务统一读取再按行测现有数据合同导入。授权失效、设备验证和用户主动停止同步必须分别表达，不能将它们混为登录失效。
4. 明确跨站退出、仅退出本站、切换账号、会话过期与撤销语义。行测前端只有在身份确认匹配后才保留本机账号缓存；兑换失败时保留已有数据但不展示其他账号内容。
5. 共享身份接口应由服务端处理 Cookie、CSRF、来源限制与审计。客户端使用现有 `storeFenbiSession` 事件通知与 `AccountNotebook`/`useFenbiPractice` 的账号卸载机制，不直接读写另一站的本机存储。

## 合成验收矩阵

- **旧行测账号**：共享身份映射回同一个 `xc_fb_accounts.id`；笔记、复盘、练习与本机缓存不丢失、不重复。
- **仅公专扫码过的账号**：一次确认后可在行测取得自己的站内会话和可用题源；若授权交接不可用，明确说明身份已识别但同步尚未就绪，不显示成功假象。
- **刷新与跨站返回**：两站往返后仍是同一粉笔身份，刷新后恢复；不需要复制空间码或手工导出。
- **账号切换**：A 的请求延迟返回时切到 B，A 的练习、错题、进度和保存请求不得出现在 B；双标签页的存储事件一致。
- **退出与过期**：按最终定义执行本站或双站退出，旧站内令牌撤销；401 与中枢会话过期有清晰区别，不出现退出后立即自动登录。
- **离线**：已验证账号可看本机缓存并保留待同步复盘；不能离线确认的新身份不获得旧账号缓存；恢复联网后只同步当前账号。
- **安全边界**：伪造、过期、重放、错误受众、其他账号的断言全部拒绝；令牌不出现在 URL、日志、跨域 localStorage、错误文本或页面截图。

共享身份契约确定前，本文不引入后端接口、数据库迁移或线上发布。
