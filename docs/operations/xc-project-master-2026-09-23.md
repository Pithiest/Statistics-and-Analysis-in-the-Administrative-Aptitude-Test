## 集成与验收

1. 每个专项从当前生产提交出发，只提交自身改动；交付复现、提交、受影响测试和未验证边界。交叉文件按行为审查后串行集成，不直接覆盖另一任务的改动。
2. 统计或同步变动运行相关测试；云端变动还运行 `npm run typecheck:cloud`；前端集成运行 `npm test`、`npm run typecheck`、`npm run build`，并用隔离合成数据检查受影响的桌面、手机、键盘、深浅主题及控制台。
3. 代码合并、前端部署、Edge Function/数据库部署和正式域名验收分别记录。共享扫码 503 修复后，仍需真实粉笔 App 一次确认、两站账号映射、刷新、返回和退出验收；本人手机确认不能由合成测试代替。
4. 本地备份、有效未提交改动、浏览器个人数据和云端数据分别保留。任何源码恢复或清理都不能当作数据备份；上线或删除前核对具体影响。
