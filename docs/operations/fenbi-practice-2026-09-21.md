# 3.6.0 粉笔全部练习与自动统计

## 本次行为

- 粉笔扫码、设备验证、账号退出、停止自动同步和同步状态放到设置页，与空间码同页。
- 复盘页新增全部练习。正确、错误、未答、逐题真实用时和整次训练历史均保留；提供正确题和超过 90 秒的慢正确题筛选。题干与解析先隐藏答案，点击后揭示；回看不增加刷题量。
- 已完成练习进入总览、模块诊断与台账，默认查看当前粉笔账号的数据。原手动数据仍可切换查看，不自动叠加到粉笔来源，避免双计；账号数据不写入空间码。
- 打开网站自动检查历史，距上次读取超过 15 分钟自动安排更新；云端原有分钟调度继续分批工作，完成后每 6 小时同步。网络失败保留检查点，5 分钟后再试；登录/验证失败停止并提示用户。
- 后台错题工作区在切页时保持运行，5 秒合并的笔记上传不因离开复盘页而丢失。账号退出/切换取消旧请求并隐藏旧数据。

## 来源与口径

2026-09-21 读取粉笔公开发布的官方网页程序，定位了 `getExerciseBriefHistory`、`getReport`、`getSolution` 和返回的 `static/solution` 入口。只读取本人历史返回的 exercise key；不猜测练习 ID，不提交粉笔作答。

历史列表 categoryId 3、1 均按 cursor 读取到明确的 null 结束。已完成状态为 1；未完成记录不导入。历史列表不完整地展示部分试卷题数，故总题、正确数、提交时间以完整成绩报告为准。

- `subReports[type=0].time` 是考试限时，不用于速度；使用 `courseStat.elapseTime`、模块 time 和逐题 userAnswers.time（秒）。
- 正确结果状态 1、9；错误 -1、7；部分正确 8；未答 0、6、10、11。缺失用时为 null，不补 0 秒速度。
- 卷面正确率包含未答题；练习档案另外展示实际作答和已作答正确率。配速采用有真实用时的实际作答，未答与缺失用时不进入速度分母。
- 知识点节点可能重叠；仅在题数和正确数构成完整分区时分拆题型，缺失逐题映射时保留模块合计，不凭空分摊用时。
- 当前错题的 universal/auth/solutions 接口不支持正确题。正确题详情通过本人已完成练习的 getSolution 返回地址读取；按官方 getTis 追加 routecs 和 static type。阅读材料通过 card 中 materialKeys 与材料 globalId 精确对应。
- 每个账号、每次练习唯一键去重；同题重做保留多个作答记录。逐题内容首次回看自动读取整次练习并缓存，按账号与题号仅保留一份，减少重复占用。

## 存储与部署

数据库新增 `xc_fb_exercises`、`xc_fb_question_cache`，均启用 RLS，撤销 public/anon/authenticated 权限，仅允许 service_role。所有站内 API 依据服务器校验的网站会话定位账号，不接受浏览器传入的 owner 作为授权依据。

`fenbi_practice.sql` 扩展账号的历史检查点与轻量状态视图。视图使用 security_invoker。账户原错题、笔记、原手动训练与空间码均保留。

Edge Function 版本 10 包含完整历史、正确题详情和用时口径。函数使用既有自定义会话鉴权，保持 verify_jwt=false；worker 仍需独立内部凭据，不向匿名调用开放业务数据。
