# 3.4.0 界面与稳定性更新

日期：2026-09-21（Asia/Shanghai）

工程：`/Users/pithiest/good_things`

状态：实现与本地验收已完成；记录定稿时线上发布仍在进行，尚未记为部署完成。

## 本轮变化

- 调整工作台层级、导航、信息排布、表单与手机记录展示，统一深浅主题；保留录入、诊断、复盘、台账、模板和同步能力。
- 补齐页面切换、区块进入、按钮反馈和进度变化动效，尊重系统减少动态效果偏好。
- 修正总览题量与正确率双轴图的组合渲染，图表提示框适配深浅主题。
- 样式使用常规加载方式，消除旧预加载方式与页面缓存的资源不匹配警告。
- 本机记录初始化完成后才允许持久写入与正常操作，避免初始空状态覆盖已有记录。
- 存储写入失败不再显示成功保存，提供明确提示与导出备份入口。
- Service Worker 更新就绪后提示用户刷新，不再因控制器切换强制刷新当前页面。
- 计时按实际经过时间累计，后台停留后仍能继续累计，暂停后可填回训练用时。
- Git 工作目录成为源码维护和构建入口。开发、构建及 GitHub 验证不再自动恢复云端源码；历史源码恢复保留为显式 `source:restore` 命令。

## 已完成验收

- 9 项测试通过，覆盖数据统计、输入校验和本机存储异常；类型检查与生产构建通过。
- 浏览器实际检查 1440 像素桌面、768 像素平板、390 像素手机与 320 像素窄屏设置页，并检查深浅主题。
- 最终生产构建在浏览器控制台为 0 条消息；设置页备份入口及按需展开的自检说明正常。
- 录入 20 题、正确 16 题、用时 15 分钟，得到正确率 80%、配速 45 秒/题；正确数大于题量时被拦截。
- 保存后刷新，记录仍保留；台账搜索无结果后清除条件能恢复展示。
- 删除记录后可撤销；复盘完成操作生效。
- 计时在页面后台停留后继续累计，暂停后可以回填用时。

- 手机验收使用本机浏览器视口模拟，未在实体手机上测试。
- 本轮未改写真实云端训练数据，未将本地测试当作真实跨设备同步验收。
- 已修改 Service Worker 更新行为，但未来版本的完整更新周期尚未实测。
