# 3.5.0 粉笔错题本与云端同步

日期：2026-09-21。该记录用于继续维护当前工程，不包含真实题目、个人答案、账号凭据或扫码令牌。

## 本轮范围

在「错题复盘」中增加「粉笔错题本」，保留原来的训练复盘。新错题库独立于训练统计、空间码同步和训练记录存储，不把题目导入或复习次数伪装成训练成绩。

连接采用每名使用者分别扫码的云端方案。网站接入独立于 ChatGPT/Codex 插件；浏览器不提交粉笔密码、不接收粉笔 Cookie。云端在有效授权会话下只读当前行测错题、材料、解析、知识点和原作答。每次成功同步后安排 6 小时后的下一次更新，人工同步可提前排队。遇到登录或验证要求时保留旧数据并要求重新扫码，限流则退避重试。

复盘支持先作答再揭示、原答案对照、笔记和间隔复习。再练为 10 分钟，模糊为 1 天，掌握按 1、3、7、14、30、60 天推进。原题来源更新与笔记、复习记录使用不同时间字段合并；并发复习事件按稳定标识保留。

## 工程入口

- `src/mistakes.ts`：来源导入、批次材料映射、复习计划、笔记和云端合并。
- `src/MistakesView.tsx`、`src/mistakes.css`：错题列表、筛选、作答、解析和复习界面。
- `src/MistakesWorkspace.tsx`、`src/mistakeApi.ts`：扫码状态、账号隔离、云端拉取与进度同步。
- `src/mistakeStorage.ts`：按账号隔离的 IndexedDB；未登录导入使用单独存储入口。
- `supabase/functions/fenbi-cloud/index.ts`：鉴权、一次性扫码事务、进度合并和同步任务。
- `supabase/functions/fenbi-cloud/provider.ts`：受限官方主机上的只读协议、Cookie 作用域和来源响应检查。
- `supabase/schema/fenbi_cloud.sql`：服务端专用账号、会话、扫码表，Vault 密钥读取和定时任务。

当前仓库没有单独的 `PROJECT_HANDOFF.md`；README 与本操作记录作为交接入口，避免出现重复且不一致的维护说明。

云端行为测试覆盖未授权拒绝、未知或过期会话、按 token 绑定账号、拒绝未知题号与题干注入、进度版本冲突重试、清空笔记同步，以及两个同时到达的扫码请求只能创建一枚会话。已消费的扫码事务重放被拒绝；Cookie 和临时扫码状态在数据库请求中为密文，篡改密文会在访问粉笔前失败。

对已有私有导出的结构验收仅在内存完成：题号唯一、批次材料映射成功、无空题干或未分类题，网站备份导出后可无损再导入。私人导出没有复制进本工程，也不作为测试样本或部署资源。

对前端账号工作区的只读审查确认：账号与令牌变更会重建工作区，退出会中止旧请求，服务端返回的账号标识需与当前工作区一致，进度响应按当前本机状态合并。审查发现并回读了三项修复：匿名导入在文件读取后重新合并最新本机进度；本机读取失败时不进入正常写入与云同步流程，并提供重试；题目阅读页区分真正编辑过的笔记与云端更新，避免离开页面时把旧文字覆盖回云端。代码回读与浏览器故障回归应分别记录，不能相互替代。

## 运维与数据边界

生产源码以本 Git 工程为准。前端和 Edge Function 分别部署；更新网页不会自动更新云端函数或数据库。实际发布、函数部署、权限与定时任务状态以当次操作回读为准。

`xc_fb_accounts`、`xc_fb_sessions`、`xc_fb_logins` 均仅供服务端操作；不能给匿名客户端添加直读策略。粉笔会话的 AES-GCM 密钥来自 Vault，运行时密钥只允许服务角色读取，不能放进前端变量、日志或截图。站内令牌只存哈希。原训练 `xingce_sync` 的业务数据不属于本轮错题同步范围。

源数据写入与进度写入独立，worker 通过限时租约与条件写入防止过期任务覆盖重连或停止同步后的状态。源批次未完整返回时保留上次成功结果。登录失效与限流分别处理，不通过伪造设备或绕过验证维持读取。

退出网站账号只注销当前会话并隐藏当前页面记录；停止自动同步会移除云端粉笔会话并停止后续读取，已有错题和复盘保留。浏览器中的各账号缓存也仍在本机；清理或迁移前分别导出训练备份与错题备份。
